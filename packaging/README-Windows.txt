SEO Data Workspace for Windows
================================

Start
-----
Double-click "SEO Dashboard.exe". The dashboard starts locally and opens in
your default browser. Keep this folder together; do not move only the EXE.

Stop
----
Double-click "Stop SEO Dashboard.exe" when you finish.

Updates and data
----------------
Download and extract the new release, then launch it. Your projects and history
are stored separately in:

  %LOCALAPPDATA%\SEO Data Workspace

Replacing or deleting this application folder does not delete that data.
Use Settings > Download backup before important updates or transfers.

The service listens only on 127.0.0.1 and does not require internet access.
