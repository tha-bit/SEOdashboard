# Main SEO Column Names and Meanings (Screaming Frog SEO Spider)

These are the highest-priority columns for an application to recognise when importing Screaming Frog SEO Spider exports.

| Screaming Frog column | Meaning for my app |
|---|---|
| `Address` | Page URL |
| `Content Type` | Content or MIME type |
| `Status Code` | HTTP status code (200, 301, 404, etc.) |
| `Status` | HTTP response status text |
| `Indexability` | Whether the URL is indexable |
| `Indexability Status` | Reason a URL is not indexable |
| `Title 1` | First meta title / title tag |
| `Title 1 Length` | First title character count |
| `Title 1 Pixel Width` | First title's pixel width |
| `Meta Description 1` | First meta description |
| `Meta Description 2` | Second meta description |
| `Meta Description 1 Length` | First description character count |
| `Meta Description 1 Pixel Width` | First description's pixel width |
| `Meta Description 2 Length` | Second description character count |
| `Meta Description 2 Pixel Width` | Second description's pixel width |
| `Meta Keyword 1` | First meta keywords tag |
| `H1-1` | First H1 |
| `H1-1 Lenght` | First H1 character count |
| `H1-2` | Second H1 |
| `H1-2 Lenght` | First H1 character count |
| `H2-1` | First H2 |
| `H2-2` | Second H2 |
| `Word Count` | Number of words in the configured content area |
| `Text Ratio` | HTML text-to-code ratio |
| `Canonical Link Element 1` | First HTML canonical target |
| `Meta Robots 1` | First robots meta tag directives |
| `X-Robots-Tag 1` | First HTTP robots directive |
| `Crawl Depth` | Click depth from the start URL |
| `Inlinks` | Internal links pointing to the URL |
| `Outlinks` | Internal links leaving the URL |
| `External Outlinks` | Links to external sites |
| `Link Score` | Screaming Frog's internal link equity score |
| `Response Time` | Time to retrieve the URL |
| `Redirect URI` | Redirect destination |
| `Redirect Type` | Redirect type |
| `Language` | Language of the page |
